# 朱苏 · ZHU × SU

独立静态网站发布包，已包含最终确认的图片与比例，不含调试功能或候选图库。

建议新建独立仓库 zhusu-coop。解压后，将本目录里的 index.html、css、js、data、img、.nojekyll 和 README.md 放到仓库根目录。不要只上传 ZIP；GitHub Pages 不会把 ZIP 自动解压成网站。

在仓库 Settings → Pages，选择 Deploy from a branch，然后选择 main 和 /(root)，保存。发布后访问 https://你的用户名.github.io/zhusu-coop/ ，以 Pages 页面实际显示的网址为准。

可以与其他项目仓库并存，每个仓库有自己的项目网址。资源地址使用相对路径；浏览器收藏进度按本网站标识与路径隔离。

网站不需要 Node 服务或安装依赖；视频点击后进入 B 站，外部字体需要联网。
